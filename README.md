# Site-Barbearia

# ✂️ Sistema de Agendamento - Barbearia do Neguinho

Este é um projeto de estudo para o curso de Análise e Desenvolvimento de Sistemas. O objetivo é facilitar o agendamento de clientes via WhatsApp.

## 🚀 Guia de Comandos Git (Para não esquecer)

Sempre que terminar uma alteração no código, siga estes passos no terminal:

1. **Preparar os arquivos:**
   ``` git add . ```

2. **Gravar a versão (com uma mensagem do que foi feito):**
   ```git commit -m "Minha mensagem aqui" ```

3. **Enviar para o GitHub:**
   `git push`

4. **Sincronizar se estiver em outro computador:**
   `git pull`

---

## 💻 Como rodar o projeto em uma nova máquina
Se você trocar de computador novamente, basta abrir o terminal e digitar:
`git clone https://github.com/GUILHERME-GTS/Site-Barbearia.git`
